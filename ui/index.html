Multi-Vendor Router Configuration Guide

Zero-Touch Ingestion: Configure router to export flows; no manual app setup required

NetFlow v5 UDP 2055
NetFlow v9 UDP 2056
IPFIX (RFC 7011) UDP 4739
sFlow v5 UDP 6343
Cisco IOS-XE / IOS-XR (Flexible NetFlow / IPFIX) 
flow record REC-AEGISFLOW
 match ipv4 protocol
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 collect counter bytes long
 collect counter packets long
 collect timestamp sys-uptime first
 collect timestamp sys-uptime last
!
flow exporter EXP-AEGISFLOW
 destination <THIS_SERVER_IP>
 transport udp 2056
 export-protocol netflow-v9
!
flow monitor MON-AEGISFLOW
 exporter EXP-AEGISFLOW
 record REC-AEGISFLOW
 cache timeout active 60
 cache timeout inactive 15
!
interface HundredGigE0/0/0/1
 ip flow monitor MON-AEGISFLOW input
 ip flow monitor MON-AEGISFLOW output
Juniper Networks Junos (Inline IPFIX) 
set services flow-monitoring version-ipfix template IPFIX-TMP flow-active-timeout 60
set services flow-monitoring version-ipfix template IPFIX-TMP flow-inactive-timeout 15
set forwarding-options sampling instance FLOW-INST input rate 1000
set forwarding-options sampling instance FLOW-INST family inet output flow-server <THIS_SERVER_IP> port 4739
set forwarding-options sampling instance FLOW-INST family inet output flow-server <THIS_SERVER_IP> version-ipfix template IPFIX-TMP
set interfaces et-0/0/0 unit 0 family inet sampling input
Huawei VRP (NetStream v9) 
ip netstream export host <THIS_SERVER_IP> 2056
ip netstream export version 9
ip netstream timeout active 1
ip netstream timeout inactive 15
!
interface 100GE1/0/1
 ip netstream inbound
 ip netstream outbound
Nokia 7750 SR / SR OS (cflowd / IPFIX) 
/configure cflowd
  active-timeout 1
  inactive-timeout 15
  collector <THIS_SERVER_IP>:4739 version ipfix
  no shutdown
/configure router interface "to-core"
  cflowd-parameters
    sampling unicast type interface
    direction both
  exit
MikroTik RouterOS (Traffic Flow) 
/ip traffic-flow set enabled=yes active-flow-timeout=1m inactive-flow-timeout=15s
/ip traffic-flow target add address=<THIS_SERVER_IP>:2055 version=5
/ip traffic-flow target add address=<THIS_SERVER_IP>:4739 version=ipfix
